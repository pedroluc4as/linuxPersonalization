# 🐧 linuxPersonalization

Repositório dedicado aos meus arquivos de configuração, temas e dotfiles para personalizar o sistema. O objetivo é manter tudo salvo e organizado para facilitar a configuração do ambiente sem precisar recriar tudo do zero.

## Conteúdo

* **Temas Globais:** Configurações de aparência para o KDE Plasma.
* **Login (SDDM):** Telas de entrada customizadas, incluindo layouts com suporte a animações/vídeos.
* **Terminal:** Arquivos de configuração para personalização da linha de comando (Oh My Posh, Fastfetch, fontes, etc.).
